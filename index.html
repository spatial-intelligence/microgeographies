8. Photo set → 3D

Reconstruction options & guidance

COLMAP always reconstructs from clean, unlabelled photos. Optional SAM labelling runs afterwards on separate copies. No monocular-depth pass runs.

Checking whether this server can run COLMAP…

Mixed landscape and portrait photos are fine: portrait phone photos are rotated upright automatically before COLMAP sees them. For a good cloud use 8+ photos of the same subject with 60–80% overlap as you move; blank walls, glass and sky match poorly.
